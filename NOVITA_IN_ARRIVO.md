# Novità in arrivo / Coming next

Cose già pronte che arriveranno con la prossima versione. / Already done, coming with the next version.
- Prima versione installabile di Tures55 Voice per Windows. / First installable version of Tures55 Voice for Windows.
- Installatore per Windows con pagine in italiano e inglese, licenza da accettare e installazione assistita. / Windows installer with Italian and English pages, licence to accept and assisted installation.
- Il programma installato si aggiorna da solo (menu Aiuto: «Cerca aggiornamenti» e «Riavvia e aggiorna»). / The installed program updates itself (Help menu: "Check for updates" and "Restart and update").
- Invito alla donazione una volta per accensione di Windows, con il codice sostenitore che lo spegne; lo stesso codice del Tures55 Dock vale anche qui. / Donation notice once every Windows start, with the supporter code that switches it off; the same code as the Tures55 Dock works here too.
- «Segnala un problema» nel menu Aiuto: il diario e il registro del nucleo, ripuliti, all'autore senza un account GitHub. / "Report a problem" in the Help menu: the diary and the engine log, cleaned, to the author without a GitHub account.
